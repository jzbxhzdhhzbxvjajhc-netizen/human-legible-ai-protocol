# Attribution and citation / 引用与署名

This file gives a safe, simple way to satisfy the attribution requirement. It does not replace the applicable license.

## Reusing or adapting protocol material

Use a visible note like this:

> Based on Human-Legible AI Protocol v0.1.1 by founding steward jzbxhzdhhzbxvjajhc-netizen and Human-Legible AI Protocol contributors, licensed under CC BY-SA 4.0. Changes were made. Canonical source and contributor history: https://github.com/jzbxhzdhhzbxvjajhc-netizen/human-legible-ai-protocol

If you did not change the material, replace `Changes were made` with `Unmodified`.

The attribution should preserve four facts:

1. the project name and version;
2. the credited steward or contributors;
3. the canonical repository link;
4. the license and whether changes were made.

GitHub will also read `CITATION.cff` and show a **Cite this repository** entry when supported.

## 中文简明版

转载、翻译或改写协议内容时，可直接写：

> 本内容基于发起人 jzbxhzdhhzbxvjajhc-netizen 与项目贡献者共同署名的《AI 人话协议（Human-Legible AI Protocol）》v0.1.1，采用 CC BY-SA 4.0 许可；本文做过修改。官方源地址与贡献历史：https://github.com/jzbxhzdhhzbxvjajhc-netizen/human-legible-ai-protocol

没改过就把“本文做过修改”换成“内容未修改”。署名不是一句空泛的“来源网络”，而是让读者能找到原项目、原版本和许可。

## Important limit / 重要边界

Copyright protects the actual text, examples, datasets, and implementation. It does not normally create ownership of the underlying idea “AI should speak plainly.” A person who independently implements the idea without copying protected material may not be legally required by copyright to cite this repository. Canonical history, project identity, conformance marks, public adoption, and community trust therefore matter alongside the license.

版权主要保护具体文字、案例、数据和实现，通常不会让任何人独占“AI 应该说人话”这个抽象想法。因此，引用条款能管住复制和改写，不能保证所有独立实现者都必须引用。项目还要依靠公开时间线、官方版本、名称、符合性标识和社区信任守住发起者位置。
